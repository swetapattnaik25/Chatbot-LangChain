# Chatbot-LangChain
Create model list and chatbot using langchain

A simple AI-powered chatbot built using Google Gemini, LangChain, and Python. This project demonstrates how to connect to Google's Gemini models, retrieve available models, and build an interactive command-line chatbot.

🚀 Features
Connect to Google Gemini API.
List available Gemini models.
Build an interactive chatbot using LangChain.
Maintain a simple command-line conversation interface.
Configure API keys securely using environment variables.

🛠️ Technologies Used
Python
Google Gemini API
LangChain
langchain-google-genai
Google Gen AI SDK
python-dotenv

📌 Learning Objectives
Understanding Google Gemini API integration.
Exploring available generative AI models.
Learning how to use LangChain with Gemini.
Working with environment variables in Python.
Building an interactive AI chatbot.
